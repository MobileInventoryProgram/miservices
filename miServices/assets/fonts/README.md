# Flyer fonts

Static TTFs embedded in the A5 price flyer PDFs (lib/flyer/pdf.tsx), matching
the fonts of the original Illustrator leaflet. Downloaded from Google Fonts.

- Roboto Slab (300, 400, 700): SIL Open Font License 1.1
- Roboto (300, 500, 700, 900): SIL Open Font License 1.1
- PT Sans (400, 700, 400 italic): SIL Open Font License 1.1

The HTML flyer loads the same families via next/font/google.
